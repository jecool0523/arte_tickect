# ARTE 티켓팅 수정 정리 — 2026-10-07

이 문서는 이전 GitHub 반영 이후의 프로필·예약 내역·관리자·팬 경험치 변경을 정리한다. 초기 프로필 등록 및 Sites 구성은 [이전 작업 정리](work-summary-2026-10-06.md)를 참고한다.

## 로그인·프로필·홈

- 이메일·비밀번호 가입/로그인 실험은 사용자 요청으로 되돌리고 Google OAuth만 유지했다. 인증/SMTP 설정을 추가 변경하지 않았다.
- 프로필 탭이 로그인/정보 등록 화면으로 다시 리다이렉트되는 원인을 수정했다. `/profile`에서 로그인 상태에 맞는 화면을 직접 표시하고, 탭 사전 읽기를 꺼서 이전 인증 상태의 리다이렉트 캐시를 방지한다.
- 로그인·프로필 화면은 기존 흰색 카드·회색 배경·보라색 버튼·하단 내비게이션 스타일을 유지한다. 로딩/재시도 화면을 추가했다.
- 홈 제목을 ‘아르떼’로 변경하고 검색 입력·검색 버튼·긴 로그인 안내를 제거했다. ‘내 티켓 확인’을 ‘내 예약 내역 보기’로 바꿨다.

## 예약 내역·티켓

홈/프로필에서 `/profile/bookings`로 이동한다. 계정에 연결된 예약을 조회하고 완료 예약의 ‘내 티켓 확인하기’에서 좌석·티켓 및 이미지 저장을 제공한다. 취소/확인 중 예약에는 유효한 티켓을 표시하지 않는다.

서버에서 확인한 사용자 ID와 본인 전용 RLS로 목록/상세를 보호한다. 다른 계정의 예약 ID로 티켓을 조회할 수 없으며 개인 응답은 private/no-store다. 상세 규칙은 [프로필·예약 문서](profile-onboarding.md)를 참고한다.

## 관리자 공연 관리

사용자가 지정한 기존 Google 계정에만 관리자 권한을 부여했다. 이메일 기반 자동 승격은 없다. 관리자는 프로필의 관리 버튼에서 기존 3개 공연의 정보·포스터·줄거리 및 일반 예매 기간을 수정할 수 있다.

공연 정보와 기간은 하나의 트랜잭션으로 저장하며 한국 시간 입력을 사용한다. 저장 결과는 공개 공연 화면과 예매·티켓에 반영된다. 신규 공연 추가/삭제, 좌석 배치 변경은 포함하지 않는다. [권한·관리 범위](admin-performances.md)를 참고한다.

## 팬 경험치

점수와 등급 기준은 [README](../README.md#팬-경험치와-등급)에 정리했다. 프로필에 현재 등급·총 XP·활동별 건수/점수·다음 등급 진행도·오늘 방문 적립 상태를 표시한다.

예약/리뷰 XP는 계정 소유 활동을 매번 집계한다. 반복 조회나 예약 동기화 자체로 추가 적립하지 않는다. 로그인 리뷰는 기존 삭제 토큰 검증을 유지하면서 서버가 검증한 사용자 ID에 원자적으로 연결한다. 익명 리뷰 작성은 계속 가능하지만 XP에 포함되지 않는다.

방문 기록은 `private.fan_visits`의 `(user_id, visit_date)` 기본 키로 중복을 방지한다. 실제 보이는 로그인 화면에서 방문 요청을 보내며 날짜는 DB의 한국 시간으로 결정한다. 프로필 삭제 시 방문 기록도 cascade 삭제한다. 새 테이블은 RLS를 켜고 브라우저 역할 권한을 제거했다.

`GET /api/profile/fan-experience`는 본인 집계만 조회한다. `POST`는 빈 JSON 객체 `{}`만 받아 오늘 방문을 기록하며 출처 검사·요청 제한을 적용한다. 계정 ID·점수·날짜 위조 입력은 거부한다. 세 함수 모두 SECURITY INVOKER이며 service_role 전용이다. 서버 비밀값은 브라우저에 노출하지 않는다.

원격 Supabase migration: `account_fan_experience`. 검토 가능한 SQL 소스는 `scripts/fan-experience-schema.sql`이며 원격 migration history가 적용 기준이다. 기존 SQL 전체를 일괄 재실행하지 않는다.

## 검증 결과

- 프로필 입력·폼·API·탭 이동, 본인 예약 조회/다른 계정 거부, 관리자 공연 API 및 보안 회귀 검사 통과.
- `scripts/test-fan-experience.mjs`: 등급 경계값, 본인 UID 바인딩, 위조 필드/교차 출처 거부, 요청 제한/조회 실패, 로그인·익명 리뷰 분기 통과.
- 실제 DB의 하루 방문 중복 방지·한국 날짜·리뷰 소유자/삭제 토큰·리뷰 삭제 제외·예약 연결/취소/완료 집계를 트랜잭션으로 검증하고 테스트 변경은 ROLLBACK했다.
- 로컬 로그인 계정에서 새싹 팬 10 XP, 방문 1일, 다음 등급까지 190 XP를 확인했다. 새로고침과 배포용 Worker 미리보기에서도 방문은 1일로 유지됐다.
- 전체 Sites 빌드·타입 검사, Worker 경로/인증 장벽/개인 캐시/정적 파일/콜백·공개 파일의 비밀값 미포함 검사 통과. 기존 이미지·hook 관련 lint 경고는 남아 있다.
- Supabase 권한 검사에서 새 함수의 익명/일반 사용자 실행 및 방문 테이블 직접 접근이 차단됨을 확인했다. 서버 전용 RLS 테이블의 정책 없음 정보 알림과 기존 GraphQL 발견 가능/유출 비밀번호 보호 경고는 남아 있으며 전체 보안 인증을 의미하지 않는다.

Sites에는 기존 소유자 전용 접근 범위를 유지하여 게시했다. 이 문서의 GitHub 정리/푸시는 배포본의 기능 변경이나 재배포를 요구하지 않는다.
